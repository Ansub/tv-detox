# What each preinstalled app is, and whether it's safe to turn off.
# Read by candidates.sh (verdicts), install.sh (launchers) and apply.sh (what it refuses).
# docs/debloat.md explains the rules behind the verdicts.
#
# One app per line, three columns separated by tabs:
#
#   verdict   package   what it is, in plain words
#
#   never     the TV needs it to start or keep working. apply.sh refuses to turn it off.
#   launcher  the TV's own home screen. Only install.sh turns it off, so undo.sh can put it back.
#   keep      carries a feature you may use (casting, search, Live TV). Off only if you don't use it.
#   safe      commonly preinstalled junk: ads, sponsored rows, store demos, unused vendor apps.
#   app       an app on the TV's app list (Netflix, YouTube). Yours to keep, or to turn off if unused.
#
# Vendors rename and add apps all the time, so treat this as strong hints, not gospel. An app that
# isn't here gets a verdict from what the TV says about it (see candidates.sh), or "review".
# To add a TV: run candidates.sh, check what each "review" app does, and add a line here.
